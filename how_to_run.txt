Mesh mode (default; initiator unless role-responder is given):

For uni-dev board (STM32L431):
cargo run --release
or (responder, duty-cycled RX with DW3000 DEEPSLEEP):
cargo run --release --features role-responder

For BU03 (doesn't really work):
cargo run --release --target thumbv7m-none-eabi --no-default-features --features board-bu03,role-responder

Legacy sleep-experiment ranging protocol instead of the mesh:
cargo run --release --features sleep-experiment
cargo run --release --features sleep-experiment,role-responder
